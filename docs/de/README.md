# Website-Check – Dokumentation

Der Website-Check ist ein Inhaltselement für Contao 5. Ein Besucher gibt die
Adresse einer Website ein; die Erweiterung misst sie mit Google PageSpeed
Insights, prüft HTML, Rechtsseiten, Sichtbarkeit in KI-Suchen und den Server,
lässt die Seiten auf Wunsch von einer KI lesen wie von einem Erstbesucher,
benotet sieben Bereiche mit Schulnoten von 1 bis 5 und zeigt das Ergebnis auf
der Seite, im Tausch gegen Vorname, Nachname und E-Mail-Adresse. Ein
PDF-Bericht geht per E-Mail hinaus: mit Lizenz an den Besucher, ohne Lizenz an
den Betreiber der Website.
