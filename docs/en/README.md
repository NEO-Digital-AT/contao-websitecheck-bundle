# Website Check – documentation

The Website Check is a content element for Contao 5. A visitor enters the
address of a website; the extension measures it with Google PageSpeed
Insights, runs its own checks of HTML, legal pages, AI visibility and the
server, optionally lets an AI read the pages like a first-time visitor, grades
seven areas with school grades from 1 to 5 and shows the result on the page in
exchange for first name, last name and e-mail address. A PDF report goes out by
e-mail: with a licence to the visitor, without one to the website operator.
